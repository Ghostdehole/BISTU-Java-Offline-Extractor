# 回归测试

这些测试在独立的无头 Chromium 中运行，只使用合成题目和模拟接口，不访问校园系统、不读取浏览器登录信息、不提交真实练习答案，也不调用付费 AI 接口。

建议使用 Node.js 24：

```sh
npx pnpm@11.25.0 install --frozen-lockfile --ignore-scripts
npx pnpm@11.25.0 exec playwright install chromium
npx pnpm@11.25.0 test
```

也可将 `CHROME_PATH` 环境变量设置为本机 Chrome 可执行文件的绝对路径，以使用已安装的浏览器。测试会创建独立的临时浏览器环境，不使用个人 Chrome 配置。

测试覆盖五种题型、选项关联与特殊字符、分页失败重试、登录失效、无 Key 导出、暂停与恢复、重复 ZIP 导出、筛选范围恢复、损坏图片断点、依赖加载失败、HTML 清理、离线检索与筛选，以及禁用所有 HTTP 请求后的 `file://` 图片和窄屏页面。测试时只对源代码副本增加内部状态访问器，安装用用户脚本不暴露测试接口。

这些结果验证提取器逻辑，不代表校园接口当前在线、账号权限有效或 AI 答案正确。真实平台兼容性仍须在获得授权的登录会话中另外测试。
