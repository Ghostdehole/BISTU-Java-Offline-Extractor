# 回归测试

这些测试在独立的无头 Chromium 中运行，只使用合成题目和模拟接口，不访问校园系统、不读取浏览器登录信息、不提交真实练习答案，也不调用付费 AI 接口。

建议使用 Node.js 24：

```sh
npx pnpm@11.25.0 install --frozen-lockfile --ignore-scripts
npx pnpm@11.25.0 exec playwright install chromium
npx pnpm@11.25.0 test
```

也可将 `CHROME_PATH` 环境变量设置为本机 Chrome 可执行文件的绝对路径，以使用已安装的浏览器。测试会创建独立的临时浏览器环境，不使用个人 Chrome 配置。

测试覆盖五种题型、选项关联与特殊字符、分页失败重试、登录失效、无 Key 导出、暂停与恢复、重复 ZIP 导出、筛选范围恢复、损坏图片断点、依赖加载失败、HTML 清理、离线检索与筛选，以及禁用所有 HTTP 请求后的 `file://` 图片和窄屏页面。测试时只对源代码副本增加内部状态访问器，安装用用户脚本不暴露测试接口。

这些结果验证提取器逻辑，不代表校园接口当前在线、账号权限有效或 AI 答案正确。真实平台兼容性仍须在获得授权的登录会话中另外测试。

离线阅读回归还覆盖来源（常规/伊利诺伊）、独立章节、题型、难度顺序、全文/题目范围、分词/连续文本匹配、答案显隐、程序复制与主题。7.13.0 布局测试验证搜索在左侧筛选上方且位于折叠区之外、移动端收起筛选后仍可搜索、侧栏随文档滚动而不遮住题目，以及从深处用 `/` 或 `Ctrl K` 返回搜索框。

浏览器查找测试使用 Chromium 的 `window.find` 查找屏外题目，并确认页面不拦截 `Ctrl F`；这验证网页文本可被浏览器查找，不等同于自动操控浏览器工具栏。打印测试在 print 媒体下检查全部题目与代码保留、代码不截断、屏外渲染限制解除。测试不会将简单合成页的运行时间作为真实大题库的滚动性能结论；快速滚动、图片解码和低配置设备表现需要独立测量。

筛选隐藏回归检查未匹配题目不占布局高度、不可聚焦、浏览器查找不命中，清空后恢复原 DOM、内容与交互；断言针对用户可见行为，允许不支持新 CSS 的浏览器使用 `display:none` 回退。图片回归使用已知可解码的 PNG，在题干和答案分别放入平台式固定宽高，检查窄屏缩放保持自然宽高比，且不删减图片。

7.14.0 新增覆盖平台直接答案与参考程序优先、主观题详情先行、未知平台答案不交给 AI、Key 去重与负载轮询、总并发与单 Key 上限、401／402 停用、429 冷却、超时释放、异常响应拒绝、用量与设置持久化且不保存凭据。设置测试涵盖 34 项控件、非法值、运行锁定、导入优先选择和回滚；并发分页失败仍保留连续恢复位置。图文测试验证默认不调用 OCR、完整题图输入，以及恰好 15 张图时的 4096 像素上限。

7.14.0 最终本地结果为 81 项全部通过。测试只证明上述可复现行为，不将模拟 Key、usage 或图片输入等同于真实服务可用性或答案正确率；真实授权运行、最终包独立审计与阅读页验收另见 [验证记录](../TESTING.md)。
