# BISTU Java Offline Extractor

用于 BISTU 在线练习页面的 Tampermonkey 用户脚本。先按当前章节、知识点、难度和搜索条件扫描练习题，再检查“我的作业”，只补入题库中没有的题目，将题干、选项、可取得的答案和图片导出为 ZIP。解压后打开 `index.html`，可搜索、筛选、切换主题和显示／隐藏答案。

**先获取平台答案，再进入可选 AI 阶段。** 配置 Key 后，非程序题默认先独立作答，再比较平台答案；程序题（包括英文程序题）仅在平台没有参考答案时调用 AI。 客观题缺少明确答案时会向平台提交练习答案进行验证，可能改变练习记录。多选枚举上限默认 8 个选项，可在面板调整为 1–20；组合数最多为 `2ⁿ−1`，调高会显著增加请求。超过设定上限时仍保留全部选项和提醒，不冒充已经验证。请仅在你有权访问和允许自动提交练习答案的题库中使用。

## 安装

1. 从浏览器的官方扩展商店安装 Tampermonkey。Chrome 138 及以上还需在扩展详情中开启“允许运行用户脚本”（Allow User Scripts）；其他版本按 [Tampermonkey 官方说明](https://www.tampermonkey.net/faq.php#Q209)检查。安装扩展本身不等于已经允许用户脚本运行。
2. [安装用户脚本](https://github.com/Ghostdehole/BISTU-Java-Offline-Extractor/raw/main/BISTU_Java_Extractor.user.js)，在 Tampermonkey 页面确认安装；也可新建脚本、替换全部模板内容为本仓库的 `BISTU_Java_Extractor.user.js` 并保存。更新已有脚本时确认版本，并刷新练习页面。
3. 连接能访问学校平台的网络，登录后打开 `http://10.148.168.66/Manage/Practice/index`。脚本面板应出现在右侧。若未出现，依次检查脚本是否已启用、用户脚本权限、网址是否匹配以及页面是否已刷新。

升级后以页面面板标题显示的版本为准。若以前安装的是 7.9、名称含“DeepSeek V4 & 最终开源版”的旧条目，请在 Tampermonkey 中停用该旧条目，只保留一个版本运行，避免两个脚本同时提交或覆盖面板。

脚本只匹配上述练习页面；平台地址或页面结构变化需要重新验证。JSZip 在首次启动时联网加载。只做题目提取、不填写 API Key 时，无需加载 OCR，也不会调用 DeepSeek。

## 提取与恢复

1. 在平台选择所需章节、知识点、难度或搜索词。未选择章节时扫描当前语言的全部可见题目；工具扫描页面菜单提供的全部已支持题型（最多五种），不仅是当前选中的题型。
2. 打开 **API 与设置 → 配置 Key**，可选填写任意数量的 DeepSeek API Key。逗号、分号、空格或换行均可分隔，重复项自动合并，粘贴时每行末尾的反斜杠会清理。Key 仅保留在当前页面，刷新后需重新填写，不写入 ZIP 或持久存储；切走设置页会收起输入区。可以先点 **检测 Key（不生成答案）**：仅请求官方余额接口，不生成答案、不消耗生成 tokens；检测通过不保证后续模型请求一定成功。
3. 在同一设置页按需调整分组参数。点击 **开始提取**后，依次执行练习列表扫描、练习详情与平台答案获取、作业补题去重、可选 AI 解答与复核、图片下载。并发上限默认 **6**，可以分别调整；作业详情沿用“详情与平台验证并发”。列表首页先确定总数，后续页并发读取并按页序提交，保证题号与恢复位置连续。
4. 默认启用密码保护，在 **发布与密码** 设置中填写并确认至少 12 个字符的密码；也可主动选择公开阅读。完成后点击 **保存完整 ZIP**，确认下载完成，再将 ZIP **完整解压到同一文件夹**，打开 `index.html` 并输入密码。图片优先使用同目录的 `question-images.<版本ID>.pack.js`，缺失时回退到原始 `images`；两者至少保留一份。不要直接在压缩软件内预览。下载按钮可重复使用，点击只代表已触发下载，不保证文件已保存。

同学阅读已经导出的题库不需要安装 Tampermonkey、登录校园平台或填写 API Key。分发完整 ZIP 即可。新一年的采集者需要按上面的安装步骤重新检查运行环境。

运行中点击 **暂停并保存断点**，等待在途请求结束并完成打包，再点击 **保存断点 ZIP**。可在同一页面恢复，也可重新打开平台后导入 ZIP。页面崩溃前没有保存过的进度无法恢复。**开始新任务**会清空内存中的题目、图片、计时和用量，保留参数及 Key，并回到准备状态；不会立即发出采集请求。尚未触发保存时会先提示，取消不改变进度。

新版断点包保存原始筛选条件和运行设置。恢复时始终沿用包中的题库筛选条件，避免将不同章节混在一起；不允许跨平台来源恢复。导入前可选择 **恢复断点设置（不含 Key）**（默认，`snapshot`）或 **沿用当前面板设置**（`current`）。两种策略都不会恢复 Key；正在扫描的每页题数始终沿用断点记录，避免改页大小后重题或漏题，旧分页断点按每页 10 题兼容。旧版缺少筛选条件的未完成列表快照会拒绝恢复，请重新扫描。

7.19.2 的工作台分为 **任务概览、API 与设置、运行日志**。头部进度、页签和底部操作保持可见，内容区域独立滚动；方向键、Home／End 可切换页签。支持跟随系统、浅色和深色，只持久化主题偏好。浮动面板的拖动、八向缩放、最大化／还原、耗时统计继续保留，窗口缩小时自动回到可见范围。

运行、导入、打包和 Key 检测共用状态锁，防止重复启动；安全暂停后可以修改设置。参数错误会定位到对应输入框，失败导入保留旧任务。日志可筛选、复制、清空和选择是否跟随最新；复制前同样隐藏 Key，清空日志不会清空题目。Key 全部失效时，可补充 Key，或清空输入后继续导出已有答案。

列表、详情或 AI 请求失败时，任务会停止并尽可能生成未完成快照。恢复会重试未完成项目，不会把请求失败当作“题库为空”。图片下载会继续检查整条队列，尽量保存其余可用图片；网络错误、服务异常或图片无法解码仍使产物保持未完成。

原图连续返回 HTTP 404／410 时，记录为“平台原图不可用”，保留替代文字和手动原图链接，继续提取。此时采集流程可以完成，但页面和报告明确显示图片不齐，`imagesComplete` 为 `false`，不会声称原图已经保存。后续导入 ZIP 会重新尝试这些原图。离线页面不会自动联网补图。

## AI、Key 与运行设置

### 作业补题（7.18.0）

- 从练习页启动；**作业缺题检查默认开启**，也可关闭以仅导出练习。作业扫描遍历 `StudentJob/Index` 提供的班级、页面学期条件和全部分页，只纳入与当前练习语言相同的作业。练习页的关键词、章节、难度不会用于过滤作业。
- 使用页面本来提供的“查看”流程读取作业成绩详情；不会“开始作答”、提交作业或运行评分。学生已选选项、个人代码、得分、姓名、学号和带用户标识的详情链接不写入题库。只有明确标注为标准／正确／参考答案的内容才视作平台答案。
- 练习题优先保留编号、正文、分类和已有平台答案。按题型、标识与内容核对，再用题干、输入输出要求、选项、空位及原图地址作完整对比；不同标识但完整内容相同也只保留一题。代码空白、上下标、表格行列和列表编号均参与核对；同标识内容发生变化时保留独立版本并提示，不用标题或相似关键词直接合并。报告的 `homework.matchRecords` 逐题记录所属作业、原题标识和匹配方式，可回查每次合并依据。
- 来源筛选新增 **学期作业**，包括所有已取得的作业题；与练习题重复的题通过作业关联出现在这个分类中，全文只保存一份。仅在作业中出现的题标记 **作业独有**，追加到末尾；英文作业题归入伊利诺伊，其中程序题显示 **Programming**。全部平台答案读取结束后才开始 AI。全库总数为去重题数，来源分类可以重叠，不能相加；页面同时显示当前命中数和全库去重总数。
- 导入旧版或已完成 ZIP 会补查作业，保留已有题目、答案和图片；暂停断点逐份作业继续。作业清单变化时重新核对并幂等去重。跨作业并发响应仍按清单顺序提交，遇到失败不跳过未成功项目。
- 无可查看入口、评判中的作业会明确列入 `skipped`；页面结构变化、登录失效、分页不完整或未知题型会暂停。报告的 `homework.coverageComplete` 表示可核验的作业范围是否完整；离线页面会显示未纳入提醒。平台尚未公开的内容无法由工具恢复。

旧文件不含 `state.json` 时不能用于断点补题；网站更新包仅用于部署，请使用完整提取 ZIP。

平台答案获取覆盖每道题的实际列表和详情响应，不依赖固定题号或本学期题型数量。填空／程序题的列表没有可用答案时，先读取并核验官方详情。程序题已有明确平台答案或参考程序时不调用 AI；非程序题默认进行下述独立复核。未知的非空答案对象、无法明确映射的答案字段会保留原始数据和提醒，不能当作“没有答案”直接交给 AI。旧断点也会重新核对这些条件，避免过时的 `NeedsAI` 标记覆盖已有平台答案。

已配置 Key 后，待解答或待复核的题目会将题干及所需题图发送到 DeepSeek，产生相应 API 费用；比较阶段还会发送平台答案及其图片。默认图文模式使用 `deepseek-flash`，有平台答案的非程序题正常成功时需两次请求（独立作答、比较），无平台答案时只生成一次；程序题不进行第二次比较，重试可能增加调用。无图普通题默认 Flash，无图程序题默认 `deepseek-v4-pro`。可以改为本地 Tesseract OCR 后解答；OCR 二次 AI 纠错默认关闭，开启会增加一次清洗请求及其费用。图片缩放仅用于 AI 输入，ZIP 保留原图。题图读取或识别失败时保留未解提醒，不用残缺题图生成答案。

非程序题复核默认开启，单选、多选、判断、填空均适用：

1. 模型先根据原始题干、全部选项和题图独立解答，首请求不包含平台答案或答案图片。保留代码换行、引号、反斜杠和选项顺序；不得把疑似笔误改成另一道题。选项使用固定标识，未知或重复标识会被拒绝。无法安全分离的内联答案会保留未复核提醒。
2. 有平台答案时，再用一次请求比较两份答案。平台答案不覆盖，AI 原答案也始终保留，一致时可展开查看。多解、没有有效选项、题面错误、信息缺失和版本差异分别记录原因；有实质问题或条件限制时不标成无条件一致。模型判断一致不等于人工证明正确。
3. 无平台答案时保留独立 AI 解答；程序题包括英文程序题也按此规则补缺，但不做第二次比较。不填 Key 不调用模型，未复核题不会标作一致。
4. 返回无效 JSON、空输出、未知选项或截断时暂停；有效独立答案已保存后，恢复只重试比较。题干、选项、平台答案、Java 作答版本或复核协议改变时需要重新复核。旧协议答案不会丢失，无 Key 时保留并注明待按新规则复核；配置 Key 后才重新执行所需请求，不能把旧结果冒充新版复核。
5. 可在运行设置选择“仅为缺少平台答案的题目生成 AI 答案”，保留旧版省费模式。`extraction-report.json` 的 `answerReview` 分别统计一致、不一致、不确定、等待比较和未复核。
6. **Java 作答版本默认“未指定”**，可选择 8／17／21／25／26。题面明确指定版本时以题面为准；未指定时必须说明会改变结论的版本差异。默认不启用预览特性。区分编译错误、运行结果与逻辑错误，不因题型是单选就强迫模型忽略其他正确选项。OCR 原始转写和可选纠错建议分别保留，纠错不替换原题。

不同 Key 按**当前在途请求最少优先，同负载轮询**分配，每个 Key 默认最多 2 个并发请求；因此一个 Key 默认最多同时请求 2 次，多个 Key 才可能用满总并发 6。同一账户的多个 Key 仍共享服务端额度。HTTP 401／402 会停用本次运行中的对应 Key 并切换其他 Key；429 按 `Retry-After` 和退避规则冷却整个调度器，不通过不断换 Key 绕过限流。可用 Key 全部失效时暂停，等待更新 Key 后恢复。

面板提供 **38 项可调设置**，并有恢复默认按钮；密码及确认密码独立输入，不属于可保存设置：

| 设置组 | 默认值与可调内容 |
| --- | --- |
| 并发（5 项） | 列表、详情与平台验证、AI、图片各 **6**；单 Key **2**。均可调 1–32。 |
| 平台请求（6 项） | 每页 **10** 题（1–100）；超时 **30 秒**；读取总尝试次数 **3**；请求间隔 **100 毫秒**；重试基础间隔 **500 毫秒**；多选枚举上限 **8**（1–20）。平台答案提交不自动重试。 |
| 图片、OCR 与依赖（7 项） | 图片超时 **30 秒**、总尝试 **3**、重试间隔 **500 毫秒**、解码超时 **10 秒**；AI 图片最长边 **8192 像素**；OCR 超时 **60 秒**；依赖加载超时 **20 秒**。 |
| AI 请求（7 项） | 超时 **180 秒**；临时故障总尝试 **3**（含首次）；退避基础 **1 秒**、上限 **30 秒**；单 Key 请求间隔 **0 毫秒**；`max_tokens` **32768**（含思考 tokens）；非思考温度 **0.2**。 |
| 日志（1 项） | 面板保留 **1000** 条。 |
| 模式与恢复（7 项） | 非程序题 AI 复核 **独立作答后比较**；作业缺题检查 **开启**；导入设置策略 **snapshot**；思考模式 **开启**；思考强度 **high**；图片模式 **直接图文**；OCR 二次 AI 纠错 **关闭**。 |
| 模型（3 项） | 普通题 **deepseek-flash**；程序题 **deepseek-v4-pro**；含图片题 **deepseek-flash**，后者须支持视觉。 |
| Java 版本（1 项） | **未指定**；可选择 8／17／21／25／26，题面版本优先。 |
| 发布保护（1 项） | **密码保护**；可主动切换为公开阅读。密码不进入设置快照。 |

思考模式开启时不发送温度参数。输出达到 token 上限、空答案、拒答或响应未正常结束时不会标记完成。网络超时的请求可能已在服务端执行并计费，重试可能产生额外费用。面板／提取报告记录请求次数和服务端返回的 token 用量；它们不是账户账单，无法计算未返回用量的请求。模型和参数的实际可用范围以 [DeepSeek 官方说明](https://api-docs.deepseek.com/quick_start/pricing/)及服务端响应为准。

## 离线阅读与筛选

### 互动练习（7.20.0）

- 隐藏单题或全部答案会开启对应作答区；显示答案时收起作答区，保留本页已输入的内容。全局和单题另有作答区开关，可独立控制，不改变答案显隐。
- 单选、判断题点击选项后即时反馈；多选题选完后点击核对，避免尚未选完就判错。优先直接使用原题选项，不重新排列文字，也不复制整套选项图片。无法可靠映射时提供自评，不猜测答案字母。
- 无争议且可明确对应平台参考的客观题按平台参考反馈对错，并说明依据；存在分歧、多解、题面问题或版本条件时，只说明与双方答案各自是否相符，不宣称唯一正确。仅有 AI 答案时同样标明其参考性质。
- 填空题按可确认的空位提供输入，只有可明确逐空对应的答案才做精确文本对照；不以忽略大小写、模糊相似度或随意拆分答案判断 Java 代码正确性。程序题提供空白代码编辑框，**不执行、不编译、不提交**代码。
- 程序编辑器在光标旁提示 Java 关键词和本页写过的标识符；输入至少两个字符或按 `Ctrl+Space` 展开，方向键选择，`Tab`／`Enter` 接受，`Escape` 关闭。补全完全在本地运行，不是编译器或语义分析服务。
- 草稿在当前页面内保留，搜索、筛选、题目跳转和显隐切换不会清空；刷新或关闭页面后不保留。输入内容不发送到校园平台或 AI，也不写入浏览器持久存储；打印不包含作答控件。

- **来源**包含“全部来源／常规题库／伊利诺伊／学期作业”。原练习题的 `Single-choice` 和 `Programming` 章节仍归入伊利诺伊；新增英文作业题也进入伊利诺伊，英文程序题标为 Programming。学期作业是可重叠的独立视图，包含所有作业关联题，只有新增题标“作业独有”。**章节**筛选仍可与来源、题型、难度组合。
- 难度按 **简单 → 一般 → 中等 → 困难 → 挑战** 排列，只显示当前题库实际存在的难度；未知的新难度追加在后面。
- 默认按空格分词并同时匹配；选择“连续文本匹配”可按原版的连续短语方式搜索。全文包含题号、来源和答案；“仅题目与选项”可排除答案。支持全角／半角归一化、清空、重置、`/`／`Ctrl+K` 聚焦搜索及 `Escape` 清空。
- 全局和逐题答案显隐、参考程序精确复制、跟随系统／深浅主题、回到顶部均保留。左上角使用经典 Java 杯子矢量图标，跟随主题配色，无需请求外部图片；图形来源与许可保留在生成的 HTML 中（[Devicon](https://github.com/devicons/devicon/blob/master/icons/java/java-original.svg)）。
- 桌面和平板宽度（768px 及以上）使用跟随滚动的左侧栏，包含搜索、题数、答案控制和全部筛选；iPad 横竖屏沿用此布局。较矮窗口可在侧栏内滚动或用 Tab 访问全部控件。侧栏为向外延伸的焦点光圈预留空间。
- 手机窄屏（767px 及以下）保留随滚动的“搜索与筛选”入口，点击后展开操作面板，关闭后继续阅读，筛选条件不丢失。普通打开不会自动弹出软键盘；`/` 或 `Ctrl+K` 会直接打开并聚焦搜索。搜索框有内容时 `Escape` 先清空，再按一次关闭；关闭按钮和遮罩均可关闭。页面底部为入口和安全区域留白，末题仍能完整滚入视口。更宽的横屏按实际宽度使用侧栏。
- 提前完成题目布局，全部题目保留在 DOM 中，支持浏览器查找、复制和打印。宽表格和长行仍可横向滚动，窄屏、横屏和筛选恢复后内容完整。7.16.0 修复新 Chrome 将 `white-space` 展开为多个属性时，题目原有保留空格／不换行格式被误删的问题。
- 图片保留原文件和清晰度，从成功解码的字节取得尺寸并预留原图比例，无法确认尺寸时不猜测；窄屏按原比例缩放。7.20 图片包在本地和服务器均按接近视口的图片解码，同时最多两个解码任务；离屏后释放 Blob，返回时恢复。缺失资源包可回退原图，浏览器原图请求不受这两个解码任务的上限约束。
- 运行时图片加载失败会保留提示，并为本地文件或同源网站图片提供“重试图片”；不会自动连接校园原图地址。源站已缺失的图片仍保留原有说明。
- 使用左侧“打印 / 保存 PDF”或 `Ctrl+P`／`Cmd+P`，会以两个任务逐步准备图片，再打开打印窗口。30 秒仍未准备好会显示提示、恢复按钮，允许重试；重复点击不会并行启动准备。打印沿用当前筛选和答案显隐状态；需要完整题库时先重置筛选、显示全部答案。浏览器菜单直接打印无法等待异步准备，建议使用页面按钮。

7.18.0 为 iPhone／iPad 自动开启 **兼容模式**，也可在页头手动选择自动、标准或兼容。兼容抽屉避免整页固定定位、原生模态和背景 inert；图片只在已确认尺寸时离屏回收、近处恢复，保持原图文件与比例。打印会先恢复原图，缺少 IntersectionObserver 时回退原有加载方式。iPad 横竖屏仍按桌面侧栏布局。此策略已做 Chromium／WebKit 模拟验证，实际 iPhone 系统刷新问题仍需真机复测。

完整题目、搜索缓存、主题、宽内容滚动及所有原有筛选继续保留。本地桌面的跨库阅读与网站访问按环境选择图片加载策略。大题库和原图仍占用内存，不能保证所有设备零卡顿；实际性能、已淘汰的优化实验、完整性与 Safari 验证范围见 [测试记录](TESTING.md)。

## 图片包、密码与网站更新（7.20.0）

ZIP 同时保留原始 `images/` 与单个带版本号的图片资源包。资源包逐图无损压缩、校验并按需解码，原图质量不变；包缺失、损坏或单图解码失败时尝试原图，两者都不可用时显示重试提示。离屏释放解码后的图片，靠近时恢复，打印前逐步准备图片。图片打包不影响文字搜索索引，也不保证文件更小：JPEG／PNG 通常已经压缩，JS 的 Base64 封装还会增加体积，ZIP 保留两份资源也会变大。

默认保护题干、选项、答案、题库快照、提取报告和图片包：使用 AES-256-GCM、随机盐／IV，以及 PBKDF2-SHA256 600,000 次派生。优先使用浏览器 WebCrypto，在非安全 HTTP 环境使用内置的 Noble 实现，无需联网下载解密库。密码及密钥仅留在当前页面内存，不写入本地存储、Cookie 或导出文件。切换标签页不锁定；刷新、关闭后重新打开、从浏览器页面快照恢复时需要重新输入密码。忘记密码无法由本工具找回；请自行妥善保管。

更改保护模式、密码或确认密码后，旧 ZIP 会停用；点击“重新生成 ZIP”只重新打包当前数据，不重新采集或请求 AI，生成后再点击保存。

**原始 `images/` 按要求保留，是明文备份，不在上述密码保护范围内。** 加密网站只发布 `index.html` 和它对应的 `question-images.<版本ID>.pack.js`，不要上传原图、完整 ZIP 或采集备份。若分发完整 ZIP，接收者可直接读取其中原图。成功解锁的人仍可复制、保存或截图；客户端密码保护不能阻止获授权读者转存，也不能抵御已被篡改的网站程序。服务器应使用 HTTPS。

Nginx／宝塔／1Panel 的配置和发布顺序见 [部署与缓存说明](docs/DEPLOYMENT_NGINX.md)。入口 HTML 每次访问校验更新，带版本号的资源包可长期缓存；先上传新包再更新 HTML，保留旧包供已经打开的页面使用。缓存的密文不包含密码或解密密钥。已有旧浏览器缓存、CDN 缓存或上传目录错误仍须分别处理，单靠 HTML 中的标签不能可靠禁用服务器缓存。本脚本不会强制刷新正在阅读的页面。

## 答案与完整性

答案按三大来源区分，其中平台答案保留两种取得方式；它们与“常规题库／伊利诺伊”的题库来源筛选是不同概念：

| 答案来源 | 含义 |
| --- | --- |
| 平台答案：直接提供（`platform-answer`） | 从本题明确的 `Answer` 等平台字段取得。判断题 `false`、标量 `0` 都是有效值；选项答案必须能无歧义映射，不能猜索引或未知对象。未提交验证时不标作“平台校验”。 |
| 平台答案：提交验证（`platform-verified`） | 缺少明确直接答案时，依据平台对实际选项提交返回的正确结果取得。 |
| 平台参考程序（`platform-reference`） | 程序题 `PlainExample` 原样保存，标明“未运行验证”，支持精确复制。本工具不运行或提交参考程序。 |
| AI 辅助答案（`ai`） | 平台缺少可用答案时生成，需要自行核对。另存的 `AIReview` 记录非程序题独立答案和比较结果，不覆盖平台答案。 |

- 单选、多选、判断题仍保留全部题干与选项；网络错误或无效详情不会标记为提取成功。
- 如果平台把所有现有选项均判为错误，保留题目及全部选项并显示提示，不推测或伪造平台答案。
- 填空、程序题保留平台返回的题干和要求；填空题保留可确认的空位顺序与数量。没有平台答案且未配置 Key 时，仍保留题目，不补写答案。
- AI 图文理解和 OCR 都可能读错代码、公式和图形。直接图文模式省去额外 OCR 清洗请求，不代表答案一定正确。
- 离线文件包含成功下载的题干和答案图片，兼容常见相对地址、懒加载和响应式图片。遇到尚未支持的内联 SVG／Math、视频、附件或 CSS 背景图时明确暂停，需要更新适配，不静默删除后宣称完整。
- 导出的题目富文本会清除脚本、事件属性、表单行为和远程嵌入。代码按文本转义，保留 `&`、`<`、`>` 等字符。
- “提取完成”表示采集流程完成，不表示每题都有正确答案。无 Key、无法验证的客观题、超出枚举上限的多选题、无法解析的平台答案字段，都可能保留未解状态和提醒。

## 每年重新提取

- 每年进入学校的在线练习页面后开始新任务并点击“开始提取”，不要用往年的断点包当作新题库更新。
- 脚本从页面题型菜单读取实际编号和顺序，不依赖年份、章节名或固定题数。页面新增未知题型时会停止并说明原因，避免静默漏题。
- 平台有“跳过”等无选项条目时，按原文保留并显示内容提示，不伪造选项或答案。其他无法确认的异常详情仍暂停以便重试。
- ZIP 中的 `extraction-report.json` 记录采集时间、来源、筛选条件、各题型来源总数和实际数量、平台直接答案／验证答案／参考程序／AI 答案数量、图片数量、内容提示与可取得的 AI 用量。旧断点缺少来源总数时记为 `null`。
- 核对页面各题型总数与报告的 `expected`、`collected` 一致、`duplicateIds` 为 0。图片完整时 `included` 等于 `expected`；不完整时检查 `missingAtSource` 和失败记录，并把平台缺图说明随题库一起交给同学。
- 如果学校更换系统或接口，仍需要更新适配；当前检查可发现已覆盖的结构变化，不能保证未知改版自动适配。

## 故障处理

- **登录失效或详情结构变化**：重新登录并检查练习页可正常作答，再恢复；不要将登录页当作题目导出。
- **依赖加载失败**：检查 CDN 网络访问；启动会显示错误并允许重试，不会一直停在加载状态。
- **API Key 耗尽／限流**：401／402 停用对应 Key；429 先冷却重试，服务端要求等待过久或临时重试用尽时暂停。按提示稍后恢复或补充有效 Key。模型、响应格式、网络等错误会单独报告；并非所有 API 错误都表示 Key 无效。
- **平台返回未知答案结构**：原始字段会保留，但不猜测或发给 AI 代替解析，需要检查平台适配。主观题详情无法核验时同样暂停。
- **AI 输出被截断**：提高输出 token 上限或降低思考强度后恢复；只增加 Key 数量不能解决单次输出上限。
- **图片无法下载**：检查平台原图能否打开。失败图片需要恢复重试；不能保证已失效或跨域禁止访问的资源可离线保存。

## 本地回归测试

需要 Node.js 20+，以及 npm 或 pnpm：

```sh
pnpm install
pnpm exec playwright install chromium firefox webkit
pnpm test
```

测试在独立 Chromium、Firefox 和 WebKit 实例中使用合成题目、模拟平台及 AI 响应，不连接校园系统、不使用登录 Cookie 或真实 API Key。覆盖分页失败和重试、五种题型、暂停恢复、ZIP 图片保留、导入条件、HTML 安全、代码文本及离线交互。WebKit 回归不等于真实 iPhone Safari 验收。

本地回归通过不等于本学期真实平台端到端验证通过。真实验收还需在授权账户中核对各题型总数、答案提交响应、图片资源和最终导出内容。本次验证范围见 [测试记录](TESTING.md)。
