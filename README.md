# BISTU Java Offline Extractor

用于 BISTU 在线练习页面的 Tampermonkey 用户脚本。按当前章节、知识点、难度和搜索条件扫描五种题型，将题干、选项、可取得的答案和图片导出为 ZIP。解压后打开 `index.html`，可搜索、筛选、切换主题和显示／隐藏答案。

**客观题答案验证会向平台提交练习答案，可能改变练习记录。** 多选题最多对 8 个选项枚举组合；更多选项保留题目并交由可选 AI 解答。请仅在你有权访问和允许自动提交练习答案的题库中使用。

## 安装

1. 在 Chrome、Edge 或 Firefox 安装 Tampermonkey。
2. [安装用户脚本](https://github.com/Ghostdehole/BISTU-Java-Offline-Extractor/raw/main/BISTU_Java_Extractor.user.js)，或在 Tampermonkey 新建脚本并粘贴本仓库的 `BISTU_Java_Extractor.user.js`。
3. 登录平台，打开 `http://10.148.168.66/Manage/Practice/index`。脚本面板应出现在右侧。

脚本只匹配上述练习页面；平台地址或页面结构变化需要重新验证。JSZip 在首次启动时联网加载。只做题目提取、不填写 API Key 时，无需加载 OCR，也不会调用 DeepSeek。

## 提取与恢复

1. 在平台选择所需章节、知识点、难度或搜索词。未选择章节时扫描当前语言的全部可见题目；工具会扫描全部五种题型，不仅是页面当前选中的题型。
2. 可选填写 DeepSeek API Key，多个 Key 用逗号分隔。填写后，待解题目及图片的 OCR 文本会发送到 DeepSeek，产生相应 API 费用。Key 不写入 ZIP。
3. 点击 **全新开始提取**。依次执行题目列表扫描、题干和选项提取及客观题验证、可选 AI 解答、图片下载。
4. 完成后点击 **保存提取产物**，下载 ZIP 并解压，打开 `index.html`。

运行中点击 **暂停并生成防丢 ZIP**，等待正在处理的请求停止并完成打包，再保存断点包。可在同一页面恢复，也可重新打开平台后导入 ZIP。页面崩溃前没有保存过的进度无法恢复。

新版断点包保存原始筛选条件。恢复时沿用包中的条件，避免将不同章节混在一起；不允许跨平台来源恢复。旧版缺少筛选条件的未完成列表快照会拒绝恢复，请重新扫描。

列表、详情、图片或 AI 请求失败时，任务会停止并尽可能生成未完成快照。恢复会重试未完成项目，不会把请求失败当作“题库为空”。图片下载失败时产物保持未完成；离线页面显示缺失提示和手动原图链接，不会自动联网回退。

## 答案与完整性

- 单选、多选、判断题：通过平台返回的验证结果识别答案；网络错误或无效详情不会标记为提取成功。
- 填空、程序题：保留列表接口提供的题干及要求；本工具不运行或提交生成的程序。未配置 Key 时仍然导出题目，AI 解答保持待处理。
- AI 答案明确标为 AI 生成，并非平台标准答案，需要自行核对。OCR 可能丢失缩进、公式和图形信息，不能保证图像题答案正确。
- 离线文件包含成功下载的题干和答案图片。视频、附件、复杂交互组件及 CSS 背景图不在当前导出范围内。
- 导出的题目富文本会清除脚本、事件属性、表单行为和远程嵌入。代码按文本转义，保留 `&`、`<`、`>` 等字符。
- “提取完成”表示采集流程完成，不表示每题都有正确答案。无 Key、无法验证的客观题、超出枚举上限的多选题可能没有答案。

## 故障处理

- **登录失效或详情结构变化**：重新登录并检查练习页可正常作答，再恢复；不要将登录页当作题目导出。
- **依赖加载失败**：检查 CDN 网络访问；启动会显示错误并允许重试，不会一直停在加载状态。
- **API Key 耗尽／限流**：补充有效 Key 后恢复。模型、响应格式、网络等错误会单独报告；并非所有 API 错误都表示 Key 无效。
- **图片无法下载**：检查平台原图能否打开。失败图片需要恢复重试；不能保证已失效或跨域禁止访问的资源可离线保存。

当前非思考请求使用 `deepseek-flash`，程序解答使用 `deepseek-v4-pro`。模型名称以 [DeepSeek 官方说明](https://api-docs.deepseek.com/quick_start/pricing/) 为准，实际可用性和费用取决于账户及服务状态。

## 本地回归测试

需要 Node.js 20+，以及 npm 或 pnpm：

```sh
pnpm install
pnpm exec playwright install chromium
pnpm test
```

测试在独立 Chromium 实例中使用合成题目、模拟平台及 AI 响应，不连接校园系统、不使用登录 Cookie 或真实 API Key。覆盖分页失败和重试、五种题型、暂停恢复、ZIP 图片保留、导入条件、HTML 安全、代码文本及离线交互。

本地回归通过不等于本学期真实平台端到端验证通过。真实验收还需在授权账户中核对各题型总数、答案提交响应、图片资源和最终导出内容。本次验证范围见 [测试记录](TESTING.md)。
