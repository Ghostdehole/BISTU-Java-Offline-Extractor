# BISTU Java Offline Extractor (离线题库提取引擎)

[![License](https://img.shields.io/github/license/Ghostdehole/BISTU-Java-Offline-Extractor?color=green)](https://github.com/Ghostdehole/BISTU-Java-Offline-Extractor/blob/main/LICENSE)
![Tampermonkey](https://img.shields.io/badge/Tampermonkey-Required-orange.svg)

本项目是专为 BISTU 校园网络教学平台深度定制的浏览器用户脚本（Tampermonkey Script）。
该工具旨在自动化接管原教务页面的题目解析流程，支持提取客观题（单选/多选/判断）与主观题（填空/程序），并将其构建为具备本地检索能力、跨域防盗链处理及完全脱离网络依赖的离线单页应用 (Single Page Application, ZIP 格式导出)。

---

## 核心技术特性

- **多模态 AI 推理引擎**：底层接入 DeepSeek V4 API，支持复杂程序题与填空题的自动化逻辑推导，兼容并可开启 Pro 思考模型。
- **OCR 视觉降噪与纠错兜底**：内嵌 Tesseract.js 引擎。针对非标准纯图题目，系统将自动进行图像文本剥离，并通过大语言模型进行上下文清洗与纠错。
- **零依赖离线查阅架构**：导出的 `index.html` 具备以下功能：
  - **内存级防抖检索**：基于内存缓存的 DOM 遍历算法，支持毫秒级响应，彻底解决移动端（如 iOS Safari）因高频重绘导致的内存溢出崩溃问题。
  - **自适应暗黑模式**：根据操作系统环境变量自动切换 UI 渲染主题。
  - **代码沙盒与高亮**：程序题结果展示采用自适应限制高度的沙盒容器，防霸屏并支持一键复制至剪贴板。
  - **本地化静态资源代理**：资源转储至本地相对路径，底层规避原站点的跨域限制 (CORS) 与防盗链 (Referer) 策略。
- **高并发调度机制**：采用基于状态机的并发控制逻辑，多线程同时执行 DOM 解析、网络校验与资源下载，显著提升提取效率。
- **可靠的断点续传设计**：系统支持中途挂起或在浏览器异常崩溃后恢复进度。通过反序列化之前生成的快照文件 (.zip)，即可从断开的执行栈继续运行。
- **沉浸式控制台**：注入的浮动工作台支持无限制四边/八向拉伸、网页内最大化、全局运行耗时统计以及防跳帧的日志追踪系统。

## 安装说明

### 环境前置要求
在安装本脚本前，请确保您的现代浏览器（Chrome / Edge / Firefox 等）已安装用户脚本管理器扩展，例如 **[Tampermonkey](https://www.tampermonkey.net/)**。

### 快捷安装
点击下方链接，您的扩展程序会自动拦截并弹出安装确认界面，点击“安装”即可完成部署：
[点击此处安装最新版脚本](https://github.com/Ghostdehole/BISTU-Java-Offline-Extractor/raw/main/BISTU_Java_Extractor.user.js) 

### 源码手动部署
1. 下载或打开本仓库根目录下的 `BISTU_Java_Extractor.user.js` 文件。
2. 复制代码内容。
3. 打开 Tampermonkey 管理面板，选择“添加新脚本”。
4. 将原有默认模板清空，粘贴代码并保存 (Ctrl + S)。

## 操作指南

### 1. 初始化引擎
- 登录目标系统，导航至具体的练习题或题库列表视图。
- 脚本完成注入后，将在浏览器视口右侧渲染控制台面板。

### 2. 鉴权与配置 (按需)
- 在控制台的输入区域内，配置您的 DeepSeek API Key。
- *提示：系统支持多个 Key 轮询（使用逗号分隔）以实现负载均衡。若不填写，引擎仍将提取所有客观题目，但针对程序题及填空题的主观 AI 辅助推导流程将被静默跳过。*

### 3. 任务执行机制
- **创建全新任务**：点击 `[全新开始提取]` 按钮，状态机将依次执行：列表扫描 -> 节点破解与隔离 -> AI 逻辑推导 -> 并发图片资源下载。
- **恢复中断任务**：若任务因故中止，点击 `[导入断点 ZIP 继续]` 按钮并上传最近一次生成的 `.zip` 文件，引擎将解析内部的 `state.json` 以恢复完整运行上下文。

### 4. 界面交互与控制
- **窗口调整**：控制台四周边缘均支持鼠标拖拽调整尺寸。
- **视图最大化**：点击右上角 `[铺满窗口]`，控制台将覆盖当前 DOM 视口；再次点击可还原层级。
- **日志阅读**：系统输出的标准控制流日志具备防跳帧功能。当用户向上滚动查看历史日志时，滚动条锚点将自动锁定。
- **强制中断**：运行期间可随时点击 `[暂停并生成防丢 ZIP]`，系统将执行安全中断并封装当前状态快照。

### 5. 离线产物使用
- 当主控进度达到 100% 后，点击 `[点击保存提取产物 (ZIP)]` 下载最终生成包。
- 在本地操作系统中解压该文件，使用任意浏览器打开 `index.html`。
- 本地交互支持：
  - 多维度交叉筛选（题型、难度等级、数据来源）。
  - 全文关键字快速防抖搜索。
  - 答案显隐切换，适用于自我模拟评测。

## 常见问题排查 (FAQ)

**Q：离线文件中部分图像显示“图片加载拦截”提示？**
> A：这意味着该题目的图片源在抓取时已经失效，或者存在极端严格的跨站拦截。离线页面已为您提供一个直达原始链接的入口，您可点击尝试通过独立标签页加载。

**Q：运行期间控制台抛出“API Key 耗尽”错误并挂起任务？**
> A：引擎内建了 Token 耗尽或 429 限流保护机制。此时任务进度已被冻结，您只需在配置框中补充有效的 Key 凭证，随后点击 `[恢复提取进度]` 即可无缝接续。
