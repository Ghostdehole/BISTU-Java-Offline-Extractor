# BISTU Java Offline Extractor

用于 BISTU 在线练习页面的 Tampermonkey 用户脚本。按当前章节、知识点、难度和搜索条件扫描五种题型，将题干、选项、可取得的答案和图片导出为 ZIP。解压后打开 `index.html`，可搜索、筛选、切换主题和显示／隐藏答案。

**先获取平台答案，只有确认未取得可用答案的题目才进入可选 AI 阶段。** 客观题缺少明确答案时会向平台提交练习答案进行验证，可能改变练习记录。多选枚举上限默认 8 个选项，可在面板调整为 1–20；组合数最多为 `2ⁿ−1`，调高会显著增加请求。超过设定上限时仍保留全部选项和提醒，不冒充已经验证。请仅在你有权访问和允许自动提交练习答案的题库中使用。

## 安装

1. 从浏览器的官方扩展商店安装 Tampermonkey。Chrome 138 及以上还需在扩展详情中开启“允许运行用户脚本”（Allow User Scripts）；其他版本按 [Tampermonkey 官方说明](https://www.tampermonkey.net/faq.php#Q209)检查。安装扩展本身不等于已经允许用户脚本运行。
2. [安装用户脚本](https://github.com/Ghostdehole/BISTU-Java-Offline-Extractor/raw/main/BISTU_Java_Extractor.user.js)，在 Tampermonkey 页面确认安装；也可新建脚本、替换全部模板内容为本仓库的 `BISTU_Java_Extractor.user.js` 并保存。更新已有脚本时确认版本，并刷新练习页面。
3. 连接能访问学校平台的网络，登录后打开 `http://10.148.168.66/Manage/Practice/index`。脚本面板应出现在右侧。若未出现，依次检查脚本是否已启用、用户脚本权限、网址是否匹配以及页面是否已刷新。

升级后以页面面板标题显示的版本为准。若以前安装的是 7.9、名称含“DeepSeek V4 & 最终开源版”的旧条目，请在 Tampermonkey 中停用该旧条目，只保留一个版本运行，避免两个脚本同时提交或覆盖面板。

脚本只匹配上述练习页面；平台地址或页面结构变化需要重新验证。JSZip 在首次启动时联网加载。只做题目提取、不填写 API Key 时，无需加载 OCR，也不会调用 DeepSeek。

## 提取与恢复

1. 在平台选择所需章节、知识点、难度或搜索词。未选择章节时扫描当前语言的全部可见题目；工具扫描页面菜单提供的全部已支持题型（最多五种），不仅是当前选中的题型。
2. 可选填写 DeepSeek API Key，支持任意数量，以逗号、分号、空格或换行分隔，重复项自动去重。Key 仅保留在当前页面，刷新后需重新填写，不写入 ZIP 或持久存储。可以先点 **检测 Key（不生成答案）**：仅请求官方余额接口，免费、不生成答案、不消耗生成 tokens；检测通过不保证后续模型请求一定成功。
3. 展开 **运行设置**，按需调整。点击 **全新开始提取**后，依次执行列表扫描、详情与平台答案获取、可选 AI 解答、图片下载。四阶段的并发上限均默认 **6**，可以分别调整；列表首页先确定总数，后续页并发读取并按页序提交，保证题号与恢复位置连续。
4. 完成后点击 **保存提取产物**，确认浏览器下载已完成，再将 ZIP **完整解压到同一文件夹**，打开 `index.html`。请保留旁边的 `images` 文件夹；直接在压缩软件内预览或仅复制 HTML 会导致图片缺失。

同学阅读已经导出的题库不需要安装 Tampermonkey、登录校园平台或填写 API Key。分发完整 ZIP 即可。新一年的采集者需要按上面的安装步骤重新检查运行环境。

运行中点击 **暂停并生成防丢 ZIP**，等待正在处理的请求停止并完成打包，再保存断点包。可在同一页面恢复，也可重新打开平台后导入 ZIP。页面崩溃前没有保存过的进度无法恢复。

新版断点包保存原始筛选条件和运行设置。恢复时始终沿用包中的题库筛选条件，避免将不同章节混在一起；不允许跨平台来源恢复。导入前可选择 **恢复断点设置（不含 Key）**（默认，`snapshot`）或 **沿用当前面板设置**（`current`）。两种策略都不会恢复 Key；正在扫描的每页题数始终沿用断点记录，避免改页大小后重题或漏题，旧分页断点按每页 10 题兼容。旧版缺少筛选条件的未完成列表快照会拒绝恢复，请重新扫描。

运行时设置暂时锁定，安全暂停后可以修改。浮动面板的拖动、八向缩放、最大化／还原、耗时统计和查看历史日志时保持滚动位置等原有功能继续保留。

列表、详情或 AI 请求失败时，任务会停止并尽可能生成未完成快照。恢复会重试未完成项目，不会把请求失败当作“题库为空”。图片下载会继续检查整条队列，尽量保存其余可用图片；网络错误、服务异常或图片无法解码仍使产物保持未完成。

原图连续返回 HTTP 404／410 时，记录为“平台原图不可用”，保留替代文字和手动原图链接，继续提取。此时采集流程可以完成，但页面和报告明确显示图片不齐，`imagesComplete` 为 `false`，不会声称原图已经保存。后续导入 ZIP 会重新尝试这些原图。离线页面不会自动联网补图。

## AI、Key 与运行设置

平台答案获取覆盖每道题的实际列表和详情响应，不依赖固定题号或本学期题型数量。已有明确平台答案或参考程序时不调用 AI；填空／程序题的列表没有可用答案时，先读取并核验官方详情。未知的非空答案对象、无法明确映射的答案字段会保留原始数据和提醒，不能当作“没有答案”直接交给 AI。旧断点也会重新核对这些条件，避免过时的 `NeedsAI` 标记覆盖已有平台答案。

只有仍需解答且已配置 Key 的题目会将题干及所需题图发送到 DeepSeek，产生相应 API 费用。默认图文模式使用 `deepseek-flash`，正常成功时一题一次解答请求，重试可能产生额外调用；无图普通题默认 Flash，无图程序题默认 `deepseek-v4-pro`。可以改为本地 Tesseract OCR 后解答；OCR 二次 AI 纠错默认关闭，开启会增加一次清洗请求及其费用。图片缩放仅用于 AI 输入，ZIP 保留原图。题图读取或识别失败时保留未解提醒，不用残缺题图生成答案。

不同 Key 按**当前在途请求最少优先，同负载轮询**分配，每个 Key 默认最多 2 个并发请求；因此一个 Key 默认最多同时请求 2 次，多个 Key 才可能用满总并发 6。同一账户的多个 Key 仍共享服务端额度。HTTP 401／402 会停用本次运行中的对应 Key 并切换其他 Key；429 按 `Retry-After` 和退避规则冷却整个调度器，不通过不断换 Key 绕过限流。可用 Key 全部失效时暂停，等待更新 Key 后恢复。

面板提供 **34 项可调设置**，并有恢复默认按钮：

| 设置组 | 默认值与可调内容 |
| --- | --- |
| 并发（5 项） | 列表、详情与平台验证、AI、图片各 **6**；单 Key **2**。均可调 1–32。 |
| 平台请求（6 项） | 每页 **10** 题（1–100）；超时 **30 秒**；读取总尝试次数 **3**；请求间隔 **100 毫秒**；重试基础间隔 **500 毫秒**；多选枚举上限 **8**（1–20）。平台答案提交不自动重试。 |
| 图片、OCR 与依赖（7 项） | 图片超时 **30 秒**、总尝试 **3**、重试间隔 **500 毫秒**、解码超时 **10 秒**；AI 图片最长边 **8192 像素**；OCR 超时 **60 秒**；依赖加载超时 **20 秒**。 |
| AI 请求（7 项） | 超时 **180 秒**；临时故障总尝试 **3**（含首次）；退避基础 **1 秒**、上限 **30 秒**；单 Key 请求间隔 **0 毫秒**；`max_tokens` **32768**（含思考 tokens）；非思考温度 **0.2**。 |
| 日志（1 项） | 面板保留 **1000** 条。 |
| 模式与恢复（5 项） | 导入设置策略 **snapshot**；思考模式 **开启**；思考强度 **high**；图片模式 **直接图文**；OCR 二次 AI 纠错 **关闭**。 |
| 模型（3 项） | 普通题 **deepseek-flash**；程序题 **deepseek-v4-pro**；含图片题 **deepseek-flash**，后者须支持视觉。 |

思考模式开启时不发送温度参数。输出达到 token 上限、空答案、拒答或响应未正常结束时不会标记完成。网络超时的请求可能已在服务端执行并计费，重试可能产生额外费用。面板／提取报告记录请求次数和服务端返回的 token 用量；它们不是账户账单，无法计算未返回用量的请求。模型和参数的实际可用范围以 [DeepSeek 官方说明](https://api-docs.deepseek.com/quick_start/pricing/)及服务端响应为准。

## 离线阅读与筛选

- **来源**保留原版的“全部来源／常规题库／伊利诺伊”。沿用原版分类规则：`Single-choice` 和 `Programming` 章节归入伊利诺伊，其余归入常规题库；伊利诺伊题目保留来源标记。新增的**章节**筛选独立存在，可与来源、题型、难度组合。
- 难度按 **简单 → 一般 → 中等 → 困难 → 挑战** 排列，只显示当前题库实际存在的难度；未知的新难度追加在后面。
- 默认按空格分词并同时匹配；选择“连续文本匹配”可按原版的连续短语方式搜索。全文包含题号、来源和答案；“仅题目与选项”可排除答案。支持全角／半角归一化、清空、重置、`/`／`Ctrl+K` 聚焦搜索及 `Escape` 清空。
- 全局和逐题答案显隐、参考程序精确复制、跟随系统／深浅主题、回到顶部均保留。手机上可展开筛选面板。
- 搜索、题数和“隐藏／显示全部答案”均位于桌面左侧，整个侧栏跟随滚动。窗口较矮时，侧栏可独立滚动或用 Tab 访问全部控件；滚到最后一题也不会被底部边距挤出视口。手机上控件位于题目上方，折叠筛选后仍可搜索、查看题数和切换答案。
- 提前完成题目布局，全部题目保留在 DOM 中，支持浏览器查找、复制和打印。宽表格和长行仍可横向滚动，窄屏、横屏和筛选恢复后内容完整。7.16.0 修复新 Chrome 将 `white-space` 展开为多个属性时，题目原有保留空格／不换行格式被误删的问题。
- 图片保留原文件和清晰度，从成功解码的字节取得尺寸并预留原图比例，无法确认尺寸时不猜测；窄屏按原比例缩放。本地桌面阅读提前加载图片；部署到 HTTP(S) 后，桌面按浏览器可见图片优先、后台额外最多两张预取，触控设备按需加载，减少打开页面时的集中请求。浏览器自身请求不受后台两张上限约束。
- 运行时图片加载失败会保留提示，并为本地文件或同源网站图片提供“重试图片”；不会自动连接校园原图地址。源站已缺失的图片仍保留原有说明。
- 使用左侧“打印 / 保存 PDF”或 `Ctrl+P`／`Cmd+P`，会以两个任务逐步准备图片，再打开打印窗口。30 秒仍未准备好会显示提示、恢复按钮，允许重试；重复点击不会并行启动准备。打印沿用当前筛选和答案显隐状态；需要完整题库时先重置筛选、显示全部答案。浏览器菜单直接打印无法等待异步准备，建议使用页面按钮。

完整题目、搜索缓存、主题、宽内容滚动及所有原有筛选继续保留。本地桌面的跨库阅读与网站访问按环境选择图片加载策略。大题库和原图仍占用内存，不能保证所有设备零卡顿；实际性能、已淘汰的优化实验、完整性与 Safari 验证范围见 [测试记录](TESTING.md)。

## 答案与完整性

答案按三大来源区分，其中平台答案保留两种取得方式；它们与“常规题库／伊利诺伊”的题库来源筛选是不同概念：

| 答案来源 | 含义 |
| --- | --- |
| 平台答案：直接提供（`platform-answer`） | 从本题明确的 `Answer` 等平台字段取得。判断题 `false`、标量 `0` 都是有效值；选项答案必须能无歧义映射，不能猜索引或未知对象。未提交验证时不标作“平台校验”。 |
| 平台答案：提交验证（`platform-verified`） | 缺少明确直接答案时，依据平台对实际选项提交返回的正确结果取得。 |
| 平台参考程序（`platform-reference`） | 程序题 `PlainExample` 原样保存，标明“未运行验证”，支持精确复制。本工具不运行或提交参考程序。 |
| AI 辅助答案（`ai`） | 完成平台获取后仍无可用答案时生成，并非平台标准答案，需要自行核对。已有官方答案优先于旧 AI 结果。 |

- 单选、多选、判断题仍保留全部题干与选项；网络错误或无效详情不会标记为提取成功。
- 如果平台把所有现有选项均判为错误，保留题目及全部选项并显示提示，不推测或伪造平台答案。
- 填空、程序题保留平台返回的题干和要求；填空题保留可确认的空位顺序与数量。没有平台答案且未配置 Key 时，仍保留题目，不补写答案。
- AI 图文理解和 OCR 都可能读错代码、公式和图形。直接图文模式省去额外 OCR 清洗请求，不代表答案一定正确。
- 离线文件包含成功下载的题干和答案图片，兼容常见相对地址、懒加载和响应式图片。遇到尚未支持的内联 SVG／Math、视频、附件或 CSS 背景图时明确暂停，需要更新适配，不静默删除后宣称完整。
- 导出的题目富文本会清除脚本、事件属性、表单行为和远程嵌入。代码按文本转义，保留 `&`、`<`、`>` 等字符。
- “提取完成”表示采集流程完成，不表示每题都有正确答案。无 Key、无法验证的客观题、超出枚举上限的多选题、无法解析的平台答案字段，都可能保留未解状态和提醒。

## 每年重新提取

- 每年进入学校的在线练习页面后使用“全新开始提取”，不要用往年的断点包当作新题库更新。
- 脚本从页面题型菜单读取实际编号和顺序，不依赖年份、章节名或固定题数。页面新增未知题型时会停止并说明原因，避免静默漏题。
- 平台有“跳过”等无选项条目时，按原文保留并显示内容提示，不伪造选项或答案。其他无法确认的异常详情仍暂停以便重试。
- ZIP 中的 `extraction-report.json` 记录采集时间、来源、筛选条件、各题型来源总数和实际数量、平台直接答案／验证答案／参考程序／AI 答案数量、图片数量、内容提示与可取得的 AI 用量。旧断点缺少来源总数时记为 `null`。
- 核对页面各题型总数与报告的 `expected`、`collected` 一致、`duplicateIds` 为 0。图片完整时 `included` 等于 `expected`；不完整时检查 `missingAtSource` 和失败记录，并把平台缺图说明随题库一起交给同学。
- 如果学校更换系统或接口，仍需要更新适配；当前检查可发现已覆盖的结构变化，不能保证未知改版自动适配。

## 故障处理

- **登录失效或详情结构变化**：重新登录并检查练习页可正常作答，再恢复；不要将登录页当作题目导出。
- **依赖加载失败**：检查 CDN 网络访问；启动会显示错误并允许重试，不会一直停在加载状态。
- **API Key 耗尽／限流**：401／402 停用对应 Key；429 先冷却重试，服务端要求等待过久或临时重试用尽时暂停。按提示稍后恢复或补充有效 Key。模型、响应格式、网络等错误会单独报告；并非所有 API 错误都表示 Key 无效。
- **平台返回未知答案结构**：原始字段会保留，但不猜测或发给 AI 代替解析，需要检查平台适配。主观题详情无法核验时同样暂停。
- **AI 输出被截断**：提高输出 token 上限或降低思考强度后恢复；只增加 Key 数量不能解决单次输出上限。
- **图片无法下载**：检查平台原图能否打开。失败图片需要恢复重试；不能保证已失效或跨域禁止访问的资源可离线保存。

## 本地回归测试

需要 Node.js 20+，以及 npm 或 pnpm：

```sh
pnpm install
pnpm exec playwright install chromium webkit
pnpm test
```

测试在独立 Chromium 和 WebKit 实例中使用合成题目、模拟平台及 AI 响应，不连接校园系统、不使用登录 Cookie 或真实 API Key。覆盖分页失败和重试、五种题型、暂停恢复、ZIP 图片保留、导入条件、HTML 安全、代码文本及离线交互。WebKit 回归不等于真实 iPhone Safari 验收。

本地回归通过不等于本学期真实平台端到端验证通过。真实验收还需在授权账户中核对各题型总数、答案提交响应、图片资源和最终导出内容。本次验证范围见 [测试记录](TESTING.md)。
