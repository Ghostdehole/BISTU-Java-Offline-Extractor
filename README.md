# BISTU Java Offline Extractor

用于 BISTU 在线练习页面的 Tampermonkey 用户脚本。按当前章节、知识点、难度和搜索条件扫描五种题型，将题干、选项、可取得的答案和图片导出为 ZIP。解压后打开 `index.html`，可搜索、筛选、切换主题和显示／隐藏答案。

**客观题答案验证会向平台提交练习答案，可能改变练习记录。** 多选题最多对 8 个选项枚举组合；更多选项保留题目并交由可选 AI 解答。请仅在你有权访问和允许自动提交练习答案的题库中使用。

## 安装

1. 从浏览器的官方扩展商店安装 Tampermonkey。Chrome 138 及以上还需在扩展详情中开启“允许运行用户脚本”（Allow User Scripts）；其他版本按 [Tampermonkey 官方说明](https://www.tampermonkey.net/faq.php#Q209)检查。安装扩展本身不等于已经允许用户脚本运行。
2. [安装用户脚本](https://github.com/Ghostdehole/BISTU-Java-Offline-Extractor/raw/main/BISTU_Java_Extractor.user.js)，在 Tampermonkey 页面确认安装；也可新建脚本、替换全部模板内容为本仓库的 `BISTU_Java_Extractor.user.js` 并保存。更新已有脚本时确认版本，并刷新练习页面。
3. 连接能访问学校平台的网络，登录后打开 `http://10.148.168.66/Manage/Practice/index`。脚本面板应出现在右侧。若未出现，依次检查脚本是否已启用、用户脚本权限、网址是否匹配以及页面是否已刷新。

升级后以页面面板标题显示的版本为准。若以前安装的是 7.9、名称含“DeepSeek V4 & 最终开源版”的旧条目，请在 Tampermonkey 中停用该旧条目，只保留一个版本运行，避免两个脚本同时提交或覆盖面板。

脚本只匹配上述练习页面；平台地址或页面结构变化需要重新验证。JSZip 在首次启动时联网加载。只做题目提取、不填写 API Key 时，无需加载 OCR，也不会调用 DeepSeek。

## 提取与恢复

1. 在平台选择所需章节、知识点、难度或搜索词。未选择章节时扫描当前语言的全部可见题目；工具会扫描全部五种题型，不仅是页面当前选中的题型。
2. 可选填写 DeepSeek API Key，多个 Key 用逗号分隔。填写后，待解题目及图片的 OCR 文本会发送到 DeepSeek，产生相应 API 费用。Key 不写入 ZIP。
3. 点击 **全新开始提取**。依次执行题目列表扫描、题干和选项提取及客观题验证、可选 AI 解答、图片下载。
4. 完成后点击 **保存提取产物**，确认浏览器下载已完成，再将 ZIP **完整解压到同一文件夹**，打开 `index.html`。请保留旁边的 `images` 文件夹；直接在压缩软件内预览或仅复制 HTML 会导致图片缺失。

同学阅读已经导出的题库不需要安装 Tampermonkey、登录校园平台或填写 API Key。分发完整 ZIP 即可。新一年的采集者需要按上面的安装步骤重新检查运行环境。

运行中点击 **暂停并生成防丢 ZIP**，等待正在处理的请求停止并完成打包，再保存断点包。可在同一页面恢复，也可重新打开平台后导入 ZIP。页面崩溃前没有保存过的进度无法恢复。

新版断点包保存原始筛选条件。恢复时沿用包中的条件，避免将不同章节混在一起；不允许跨平台来源恢复。旧版缺少筛选条件的未完成列表快照会拒绝恢复，请重新扫描。

列表、详情或 AI 请求失败时，任务会停止并尽可能生成未完成快照。恢复会重试未完成项目，不会把请求失败当作“题库为空”。图片下载会继续检查整条队列，尽量保存其余可用图片；网络错误、服务异常或图片无法解码仍使产物保持未完成。

原图连续返回 HTTP 404／410 时，记录为“平台原图不可用”，保留替代文字和手动原图链接，继续提取。此时采集流程可以完成，但页面和报告明确显示图片不齐，`imagesComplete` 为 `false`，不会声称原图已经保存。后续导入 ZIP 会重新尝试这些原图。离线页面不会自动联网补图。

## 离线阅读与筛选

- **来源**保留原版的“全部来源／常规题库／伊利诺伊”。沿用原版分类规则：`Single-choice` 和 `Programming` 章节归入伊利诺伊，其余归入常规题库；伊利诺伊题目保留来源标记。新增的**章节**筛选独立存在，可与来源、题型、难度组合。
- 难度按 **简单 → 一般 → 中等 → 困难 → 挑战** 排列，只显示当前题库实际存在的难度；未知的新难度追加在后面。
- 默认按空格分词并同时匹配；选择“连续文本匹配”可按原版的连续短语方式搜索。全文包含题号、来源和答案；“仅题目与选项”可排除答案。支持全角／半角归一化、清空、重置、`/`／`Ctrl+K` 聚焦搜索及 `Escape` 清空。
- 全局和逐题答案显隐、参考程序精确复制、跟随系统／深浅主题、回到顶部均保留。手机上可展开筛选面板。
- 7.13.0 将完整搜索模块移到桌面左侧、来源筛选上方，随页面正常滚动，不再悬浮遮挡题目。手机上即使折叠筛选，搜索仍可使用。
- 7.13.0 为快速滚动与跨全库跳转提前完成题目布局，并隔离各题的布局计算。全部题目、答案和图片仍保留，支持浏览器查找、复制与打印；筛选和答案隐藏在支持的浏览器中复用已有布局，不支持时使用普通隐藏方式。首次打开比7.12.0多做一次完整布局，以避免阅读中不断触发屏外题目的首次排版。
- 图片在窄屏按原图比例缩放，避免平台固定高度造成拉伸。

## 答案与完整性

- 单选、多选、判断题：通过平台返回的验证结果识别答案；网络错误或无效详情不会标记为提取成功。
- 如果平台把所有现有选项均判为错误，保留题目及全部选项并显示提示，不推测或伪造平台答案。
- 填空、程序题：保留平台返回的题干和要求；程序题的 `PlainExample` 原样作为“平台返回的参考程序（未运行验证）”展示，支持复制。本工具不运行或提交参考程序。没有平台参考答案且未配置 Key 时，仍保留题目，不补写答案。
- AI 答案明确标为 AI 生成，并非平台标准答案，需要自行核对。OCR 可能丢失缩进、公式和图形信息，不能保证图像题答案正确。
- 离线文件包含成功下载的题干和答案图片，兼容常见相对地址、懒加载和响应式图片。遇到尚未支持的内联 SVG／Math、视频、附件或 CSS 背景图时明确暂停，需要更新适配，不静默删除后宣称完整。
- 导出的题目富文本会清除脚本、事件属性、表单行为和远程嵌入。代码按文本转义，保留 `&`、`<`、`>` 等字符。
- “提取完成”表示采集流程完成，不表示每题都有正确答案。无 Key、无法验证的客观题、超出枚举上限的多选题可能没有答案。

## 每年重新提取

- 每年进入学校的在线练习页面后使用“全新开始提取”，不要用往年的断点包当作新题库更新。
- 脚本从页面题型菜单读取实际编号和顺序，不依赖年份、章节名或固定题数。页面新增未知题型时会停止并说明原因，避免静默漏题。
- 平台有“跳过”等无选项条目时，按原文保留并显示内容提示，不伪造选项或答案。其他无法确认的异常详情仍暂停以便重试。
- ZIP 中的 `extraction-report.json` 记录采集时间、来源、筛选条件、各题型来源总数和实际数量、参考程序与验证答案数量、图片数量及内容提示。旧断点缺少来源总数时记为 `null`。
- 核对页面各题型总数与报告的 `expected`、`collected` 一致、`duplicateIds` 为 0。图片完整时 `included` 等于 `expected`；不完整时检查 `missingAtSource` 和失败记录，并把平台缺图说明随题库一起交给同学。
- 如果学校更换系统或接口，仍需要更新适配；当前检查可发现已覆盖的结构变化，不能保证未知改版自动适配。

## 故障处理

- **登录失效或详情结构变化**：重新登录并检查练习页可正常作答，再恢复；不要将登录页当作题目导出。
- **依赖加载失败**：检查 CDN 网络访问；启动会显示错误并允许重试，不会一直停在加载状态。
- **API Key 耗尽／限流**：补充有效 Key 后恢复。模型、响应格式、网络等错误会单独报告；并非所有 API 错误都表示 Key 无效。
- **图片无法下载**：检查平台原图能否打开。失败图片需要恢复重试；不能保证已失效或跨域禁止访问的资源可离线保存。

当前非思考请求使用 `deepseek-flash`，程序解答使用 `deepseek-v4-pro`。模型名称以 [DeepSeek 官方说明](https://api-docs.deepseek.com/quick_start/pricing/) 为准，实际可用性和费用取决于账户及服务状态。

## 本地回归测试

需要 Node.js 20+，以及 npm 或 pnpm：

```sh
pnpm install
pnpm exec playwright install chromium
pnpm test
```

测试在独立 Chromium 实例中使用合成题目、模拟平台及 AI 响应，不连接校园系统、不使用登录 Cookie 或真实 API Key。覆盖分页失败和重试、五种题型、暂停恢复、ZIP 图片保留、导入条件、HTML 安全、代码文本及离线交互。

本地回归通过不等于本学期真实平台端到端验证通过。真实验收还需在授权账户中核对各题型总数、答案提交响应、图片资源和最终导出内容。本次验证范围见 [测试记录](TESTING.md)。
